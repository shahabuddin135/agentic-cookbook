# Task 2.4 — Auth Flow End-to-End Test

```slc
@block TASK task_2_4
priority: high
intent: "Verify JWKS → JWT decode → user_id extraction with real Better Auth tokens"
scope: phase-2
depends_on: ["2.3"]
estimate_minutes: 10

content:
  prerequisites:
    - "Next.js frontend running: http://localhost:3000"
    - "Better Auth JWT plugin configured in frontend (see 03_FRONTEND_SETUP.md)"
    - "BETTER_AUTH_URL=http://localhost:3000 in backend .env"
    - "FastAPI running: http://localhost:8000"

  manual_test_steps:
    1: "curl http://localhost:3000/api/auth/jwks | python -m json.tool"
    note_1: "Must return {keys: [{kid, kty: 'RSA', alg: 'RS256', ...}]}"

    2: "Sign in via the frontend UI (use the sign-in page)"
    note_2: "Open browser DevTools → Application → Cookies or Network tab"

    3: "In browser console: copy the JWT from Better Auth client"
    note_3: "Or use: document.cookie to find better-auth session"

    4: |
      curl -H "Authorization: Bearer <paste_jwt_here>" \
        http://localhost:8000/api/me
    note_4: "Must return {user_id: '...', payload: {...}}"

    5: "Verify the user_id matches the signed-in user in the database"

  troubleshooting:
    jwks_empty: "If /api/auth/jwks returns empty keys: check JWT plugin is installed in frontend"
    token_expired: "Better Auth JWTs expire quickly; get a fresh token for each test"
    connection_refused: "Verify both dev servers are running simultaneously"

  acceptance_criteria:
    - "JWKS endpoint returns RS256 public key"
    - "Better Auth JWT decoded correctly by FastAPI"
    - "user_id extracted matches Better Auth user.id in database"
    - "Phase 1 deliverable still holds: GET /health returns 200"
@end
```
